# Logo and Mark Design

A logo is not art. It is a functional mark that must work at 16px and on a building. Design for recognition, not decoration.

---

## Mark Taxonomy

| Type | What it is | Use when |
|---|---|---|
| **Wordmark / Logotype** | Brand name set in custom or distinctive typography | Name is short (≤3 words), distinctive, and pronounceable. Nike, Google, Coca-Cola. |
| **Lettermark / Monogram** | Initials or abbreviation designed as a unit | Name is long, awkward, or institutional. IBM, BBC, HBO. |
| **Pictorial Mark** | Recognizable real-world object simplified to icon | Brand has a strong central metaphor or narrative. Apple, Twitter, Target. |
| **Abstract Mark** | Geometric or organic shape with no literal referent | Brand needs to avoid category clichés or span multiple industries. Pepsi, Airbnb. |
| **Emblem / Badge** | Text enclosed inside a symbol or shape | Heritage, authority, or craft positioning. Universities, breweries, government. |
| **Combination Mark** | Symbol + wordmark used together as a lockup | New brands needing both name recognition and visual anchor. Most startups. |
| **Dynamic / Variable Mark** | Mark that changes form, color, or content by context | Playful, digital-native, or community-driven brands. Google Doodles, MTV. |
| **Signature Mark** | Handwritten or calligraphic treatment | Personal brands, artisanal, founder-led companies. |

**Selection heuristic:** Start with the brand's name length, personality, and primary medium. If name is ≤6 characters and distinctive, try wordmark first. If the brand spans many categories, lean abstract. If heritage matters, test emblem. Never pick a type for aesthetic reasons alone — pick for functional fit.

## Design Techniques

### Structural Techniques

| Technique | How it works | Prompt pattern |
|---|---|---|
| **Negative space** | Counter-form between or within letters/shapes carries a second image | "Create a mark where the negative space between [A] and [B] reveals [C]" |
| **Overlapping geometry** | Two or more simple shapes overlap to create a third emergent form | "Overlap [shape 1] and [shape 2] so the intersection reads as [meaning]" |
| **Visual rhythm / repetition** | Repeated elements create pattern and movement | "Repeat [element] at [interval] to build rhythm suggesting [quality]" |
| **Geometric substitution** | A letter or element is replaced by a geometric shape that carries meaning | "Replace the [letter] in [word] with [shape] that suggests [concept]" |
| **Silhouette extraction** | Reduce a complex object to its most recognizable outline | "Simplify [object] to the fewest strokes while remaining identifiable" |
| **Diagonal cut / implied motion** | Angled lines or sliced forms suggest movement or energy | "Cut [shape] at [angle] to imply [direction/energy]" |
| **Container / badge framing** | A custom-shaped boundary encloses and unifies mark elements | "Enclose [elements] inside a [shape] that reflects [brand attribute]" |
| **Symmetrical construction** | Mirror-image halves create stability, formality, trust | "Build the mark with bilateral symmetry around a [vertical/horizontal] axis" |

### Typographic Techniques

| Technique | How it works | Prompt pattern |
|---|---|---|
| **Letterform ligature** | Two or more letters share a stroke or connect organically | "Connect [letter 1] and [letter 2] through a shared [stroke/curve]" |
| **Monogram integration** | Multiple initials interlocked into a single unit | "Weave [initial 1] and [initial 2] into a unified glyph" |
| **Custom letter anatomy** | Specific letter features (bowl, ascender, terminal) are modified to carry meaning | "Modify the [part] of [letter] to suggest [concept]" |
| **Object as letterform** | A recognizable object stands in for a letter it resembles | "Replace [letter] with [object] that shares its silhouette" |
| **Wordmark with active language** | The word itself implies action or a verb | "Set the name as a wordmark where typography suggests the verb [action]" |
| **Bespoke type design** | Entirely custom letterforms designed for the brand | "Design a custom typeface for [brand] that embodies [2-3 personality words]" |

### Conceptual Techniques

| Technique | How it works | Prompt pattern |
|---|---|---|
| **Dual imagery / visual pun** | A single form reads as two different things simultaneously | "Design a mark that is simultaneously [thing 1] and [thing 2]" |
| **Hidden meaning** | A secondary message or image is embedded but not immediately obvious | "Embed [hidden element] within the mark — visible on second look" |
| **Visual metaphor** | An object symbolizes an abstract brand quality | "Use [concrete object] to represent [abstract quality]" |
| **Pattern from DNA** | A repeating pattern is derived from the mark's core geometry | "Extract the [angle/curve/ratio] from the mark and tile it into a pattern" |
| **Multi-mark system** | Several variations of the mark serve different contexts | "Design a system: primary mark, compact mark, icon-only, pattern tile" |

## Quality Criteria

Every mark must pass these tests before it ships. If it fails any, iterate.

### Functional Tests

| Test | How to run | Pass condition |
|---|---|---|
| **Favicon test** | Render at 16×16px | Mark is identifiable, not a blur |
| **Black-and-white reversal** | Remove all color, invert | Equally strong in both versions |
| **Embroidery / hat test** | Simulate thread-based reproduction | Survives with ≤3 colors and no fine detail |
| **Small-size test** | Print at 1 inch / 25mm wide | All elements legible, nothing collapses |
| **Competitor lineup** | Place among 5-8 direct competitors | Immediately distinguishable in the row |
| **Memory test** | Show for 5 seconds, ask viewer to sketch | Captured in rough sketch from memory |
| **Describability test** | Ask someone to describe it in one sentence | If they can't, simplify |
| **Context test** | Mock up on product, signage, app icon, social avatar | Works in at least 4 of these contexts |

### Quality Pillars

Seven things the designer controls — if any score below 6/10, the mark needs more work:

1. **Simplicity** — Fewer elements, fewer colors, fewer strokes. If in doubt, remove.
2. **Originality** — Does not remind you of an existing mark. Not a remix.
3. **Relevance** — Connected to the brand's story, audience, or domain — without being literal.
4. **Timelessness** — Would it look dated in 10 years? Strip trends.
5. **Beauty** — Proportions, balance, negative space all feel resolved. Not merely functional.
6. **Memorability** — One viewing is enough to recall the basic form.
7. **Story** — The mark has a "did you notice that..." moment, but works even without it.

Three things the designer does NOT control: the passage of time, the marketing budget, and the product quality. A great mark on a bad product dies.

## Bans

Reject any generated mark that matches these patterns — they are the default outputs of unconstrained image generators. Match-and-refuse.

| Slop pattern | Why it's banned | What to do instead |
|---|---|---|
| Generic swoosh / arc | Every "dynamic" brand gets one. It means nothing. | Use a specific motion path tied to the brand's actual activity. |
| Generic globe / sphere | Every "global" brand gets one. It says "we couldn't think of anything." | Find a specific geographic, cultural, or connectivity metaphor. |
| Generic leaf / sprout for "green" | Lazy shorthand for sustainability. | Use material, texture, or process imagery specific to the actual green practice. |
| Generic circuit / node for "tech" | Every AI startup logo in 2024. Indistinguishable. | Find the specific human outcome the technology enables. |
| Letter inside a circle | The most common amateur logo form. | Earn the circle: overlap, crop, or break the boundary meaningfully. |
| Gradient-dependent mark | Falls apart in single-color reproduction. | Design in black first. Add color last. |
| Over-detailed illustration | Cannot reduce to icon size. | Start at 32px and work up, not the reverse. |
| Trendy geometric low-poly | Dated within 2 years. | Use geometry with purpose, not as surface treatment. |

## AI Slop Test

**Named rule — The Stranger Test:** Show the mark to someone who knows nothing about the brand. If they say "is this a [wrong industry] company?", the mark is communicating the wrong signals. If they say "what is this?", the mark has no signal at all. The right response is "I'm not sure what they do, but it feels [personality word]."

## Process Notes

1. **Start with language, not visuals.** The brand's name, positioning, and personality words are the brief. Not "make something modern."
2. **Sketch volume before refinement.** Generate many directions (aim for 30+), then narrow. Polishing one idea too early kills the better idea you never explored.
3. **Design in black and white first.** Color is decoration. Structure must work without it.
4. **Test the system, not just the mark.** A logo exists inside lockups, patterns, favicon crops, social avatars. Design the system from the start.
5. **Present with context.** Never show a mark on a white background and ask "what do you think?" Mock it on the actual surfaces it will live on.

## Lockup Variants

Every brand needs these mark variants at minimum:

| Variant | Use case |
|---|---|
| **Primary lockup** | Default usage — symbol + wordmark in preferred arrangement |
| **Horizontal lockup** | Narrow vertical spaces: headers, banners, navigation |
| **Vertical / stacked lockup** | Square-ish spaces: social avatars, app icons, signage |
| **Symbol only** | Favicon, app icon, watermark, small-space contexts |
| **Wordmark only** | Legal documents, co-branding, when paired with other marks |
| **Badge variant** | Merchandise, stamps, circular or enclosed applications |
